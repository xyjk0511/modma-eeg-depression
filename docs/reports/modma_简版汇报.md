# MODMA 抑郁 EEG 项目简版汇报（v1.0）

## 1. 项目概览

本项目围绕 MODMA 数据集开展抑郁相关 EEG 分类研究，核心目标是验证 ERP（尤其是 dot-probe 范式下的 P300）对 MDD vs HC 的判别能力，并系统评估常见改进路径是否真正带来收益。项目已完成 16 个 phase，形成了可复现的分析与验证闭环。

- 数据基础：MODMA（128 通道，受试者级分析）
- 主任务：MDD vs HC 二分类
- 评估框架：LOSO（leave-one-subject-out）+ permutation test
- 项目状态：16/16 phase 完成，文档与代码口径一致

## 2. 数据与方法（汇报版）

### 2.1 数据与任务定义

- ERP 主线：hcue 条件下 P300 时间窗特征（250-500ms）
- 静息态分支：频段功率（5 bands x 128 通道）
- 标签：临床 MDD vs HC

### 2.2 核心建模设置

- 交叉验证：LOSO（被试级）
- 主分类器：Logistic Regression（配合标准化与 PCA）
- 统计检验：1000 次置换检验（关键实验）
- 指标：BA（主指标）、AUC、p-value

### 2.3 工程与质量控制

- 预处理增强：集成 pyprep NoisyChannels（含 RANSAC）
- 缓存策略：ERP `.npz` 缓存 + 参数哈希失效 + `--no-cache`
- 回归门：关键结果与历史基线对照
- 测试：`pytest` 通过（16 passed）

## 3. 关键结果

### 3.1 主结果（确认性）

hcue P300 128-dim 是当前最稳定、唯一统计显著主结果：

- N=52
- BA=0.670
- AUC=0.670
- p=0.022（显著）

该结果在多轮验证后保持稳定，是当前项目结论的核心支点。

### 3.2 代表性扩展实验结果

| 实验 | 结果 | 结论 |
|---|---:|---|
| 多条件融合（hcue+fcue+scue, 384-dim） | BA=0.521, p=0.411 | 性能接近随机，未优于基线 |
| 电极子集 3-dim（Pz/P3/P4） | BA=0.521, p=0.430 | 不显著 |
| 电极子集 5-dim（+Cz/CPz） | BA=0.634, p=0.045 | 显著但低于 128-dim 基线 |
| 时间窗 bin 消融（250-300ms） | BA=0.673, p=0.018 | 数值更高，但属于探索性结果 |
| 静息态频段功率（640-dim） | BA=0.391, AUC=0.366 | 明显无效，低于随机附近 |
| 跨数据集复现（MODMA→TDBRAIN） | BA=0.500, p=1.0 | 未观察到跨数据集泛化 |

## 4. 结果解读

### 4.1 可以明确支持的结论

1. 在当前 MODMA 被试级评估框架下，hcue P300 均值幅度特征有效且统计显著。  
2. 盲目“加特征/加复杂模型”并未改善结果，部分方向明显退化。  
3. 工程增强（pyprep、缓存、A/B 验证）提高了流程可信度与复现效率，但没有改变科学结论主线。

### 4.2 必须谨慎表达的点

1. 250-300ms 的 BA=0.673 虽高于 0.670，但属于时间窗探索性分析结果，应与确认性主结果区分表述。  
2. 现有跨数据集失败证据主要来自静息态路线；对同范式 ERP 的外部泛化能力仍缺少直接公开数据验证。  
3. 当前结果可支持“可复现研究发现”，但不足以支持“临床可部署模型”。

## 5. 研究价值评估

### 5.1 学术价值

- 给出了一条清晰、可复现的 MODMA ERP 基线：`BA=0.670, p=0.022`。  
- 提供了完整的负结果谱系（多条件融合、单试次、静息态、模型替换等），可减少后续重复试错。  
- 对“高维特征在小样本下退化”给出实证证据，具有方法学意义。

### 5.2 应用价值

- 目前更适合作为研究证据与论文素材，不宜宣称临床应用能力。  
- 若目标是临床转化，下一步核心瓶颈仍是同范式外部数据与样本规模，而非继续堆叠模型复杂度。

## 6. 汇报结论（建议口径）

在 MODMA 当前被试级评估中，hcue P300 128-dim（BA=0.670, p=0.022）是最稳定且统计显著的 MDD 分类结果；部分时间窗消融可达到更高 BA（如 250-300ms: 0.673），但属于探索性发现，需多重比较控制与独立数据复现。整体结论具研究价值和可发表性，但临床应用价值受限于中等性能与外部同范式验证不足。
